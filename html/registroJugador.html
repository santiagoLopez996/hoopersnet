Términos y Condiciones · Tratamiento de Datos

Última actualización: 13 de enero de 2026 · Versión: v1.0

1. Quiénes somos

HoopersNet es un proyecto operado por una persona natural (en adelante “HoopersNet”, “nosotros” o “el responsable”).

2. Qué hace HoopersNet

HoopersNet permite crear perfiles de jugadores y reclutadores para facilitar visibilidad y contacto. HoopersNet no garantiza becas, contratos, fichajes, pruebas ni resultados deportivos.

3. Requisitos y responsabilidad del usuario

  • Debes proporcionar información veraz y mantenerla actualizada.
  • Eres responsable del uso de tu cuenta y de tu contraseña.
  • No debes usar la plataforma con fines ilegales, de acoso o fraude.

4. Conductas prohibidas

  • Suplantar identidades o publicar información falsa.
  • Extraer datos masivamente (scraping) o usar bots sin autorización.
  • Publicar contenido ofensivo, discriminatorio o que viole derechos de terceros.

5. Perfiles y contenido

El usuario es responsable del contenido que publica (biografía, enlaces, videos, datos deportivos, etc.). HoopersNet podrá moderar o retirar contenido que incumpla estas reglas.

6. Contacto entre usuarios

HoopersNet puede habilitar solicitudes de contacto entre reclutadores y jugadores. Cada usuario decide qué comparte y asume responsabilidad sobre sus interacciones.

7. Suspensión y cierre de cuenta

HoopersNet podrá suspender o cerrar cuentas que incumplan estos términos o representen riesgo para otros usuarios o para la plataforma.

8. Cambios de términos

HoopersNet puede actualizar estos términos. La versión vigente se publicará con su fecha. El uso continuado implica aceptación de cambios.

Política de Tratamiento de Datos (Boceto V1)

9. Datos que recolectamos

  • Identificación/perfil: nombre, ciudad/país, categoría/nivel, datos deportivos.
  • Cuenta: correo electrónico.
  • Datos técnicos básicos para seguridad y funcionamiento.

10. Finalidades

  • Crear y administrar tu cuenta.
  • Mostrar tu perfil dentro de HoopersNet.
  • Habilitar solicitudes de contacto y funcionalidades de la plataforma.
  • Seguridad, prevención de fraude y mejora del servicio.

11. Encargados / terceros

HoopersNet usa proveedores tecnológicos (p. ej. autenticación y base de datos en la nube) para operar. Estos proveedores tratan datos solo para prestar el servicio.

12. Derechos del titular

Puedes solicitar acceso, corrección o eliminación de tus datos escribiendo a un correo de soporte que se indicará en la versión final. Para V1, este canal será el correo del proyecto.

13. Seguridad

Aplicamos medidas razonables de seguridad. Ningún sistema es 100% infalible; usa una contraseña segura y no la compartas.
